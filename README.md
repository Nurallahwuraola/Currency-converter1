#  Currency Converter

A simple and responsive Currency Converter that converts amounts between different currencies in real-time using a live Exchange Rate API.

### ✨ Features
- Convert between 100+ currencies
- Live exchange rates from API
- Swap currencies with one click
- Clean and responsive design for phone and desktop
- Instant results

###  Built With
- HTML
- CSS
- JavaScript
- Exchange Rate API
